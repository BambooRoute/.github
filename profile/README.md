# BambooRoute

A multi-model AI API gateway for developers.

[Website](https://bambooroute.com) · [API docs](https://bambooroute.com/docs) · [Model catalog](https://bambooroute.com/models)

## Projects

- **[DSH Provider](https://github.com/BambooRoute/dsh-provider)** — Connect your BambooRoute account to DeepSeek Harness and choose BambooRoute models in the model picker. [Install guide](https://github.com/BambooRoute/dsh-provider#install--%E5%AE%89%E8%A3%85) · [npm](https://www.npmjs.com/package/@bambooroute/dsh-provider)
- **[Bamboo Desktop](https://github.com/BambooRoute/desktop)** — A desktop client based on DeepSeek Harness. In development; BambooRoute sign-in and model access are not available yet.

## 中文

BambooRoute 为开发者提供统一的 API，用于接入多种 AI 模型。

[官网](https://bambooroute.com) · [API 文档](https://bambooroute.com/docs) · [模型广场](https://bambooroute.com/models)

- **[DSH Provider](https://github.com/BambooRoute/dsh-provider)**：在 DeepSeek Harness 中连接 BambooRoute 账户，再从模型选择器选择 BambooRoute 模型。[安装指南](https://github.com/BambooRoute/dsh-provider#install--%E5%AE%89%E8%A3%85) · [npm](https://www.npmjs.com/package/@bambooroute/dsh-provider)
- **[Bamboo Desktop](https://github.com/BambooRoute/desktop)**：基于 DeepSeek Harness 的桌面客户端，仍在开发中，尚未接入 BambooRoute 登录与模型调用。
